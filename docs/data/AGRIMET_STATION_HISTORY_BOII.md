# BOII historical station-location evidence

The feasibility target uses station `BOII` for 2019-07-03 through 2019-07-22.

Two archived USBR records bind the location:

- the 2013-02-26 station page reports latitude `43.60027`, longitude `116.17694`, elevation `829.06`, and installation date `7/26/1995`;
- the 2018-12-28 USBR map reports latitude `43.60027`, longitude `-116.17694`, and installation date `7/26/1995`.

The target date follows the latest archived map record. The evidence is a dated
location bracket. It is not a complete USBR relocation ledger for 2013-2019.

The registry is `data/outlook/agrimet_station_history_boii.json`. The raw
archived responses remain outside Git under the external evidence root.
