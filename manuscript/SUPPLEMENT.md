# Supplementary evidence

The manuscript appendices retain the original model visual, humidity audit, model comparisons, cropland results, seed results, compute records, and reference-ETo visuals.
The numerical evidence is stored in `docs/results/ml_transfer/` and `docs/results/ml_selective/`.

The selective results cover both input specifications, both outer evaluations, all eight methods, and every declared fault.
`coverage_curves.csv` records the inner-threshold diagnostics.
`matched_coverage.csv` records post hoc equal-budget ranking curves.
`matched_comparisons.json` records the fixed 50% paired comparisons.
`original_visuals.json` binds the exact original figure and logo bytes.

The reproduction package retains all negative outcomes, every neural seed, fit warnings, and code hashes.
It contains no claim of external validation, general agricultural improvement, or a new deferral theorem.
